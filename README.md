# Курсовой проект интеграция с внешним сервисом

## Описание:

Проект домашнего интеграция с внешним сервисом по средствам api.
Данный проект создан при прохождении обучения в онлайн-школе SkyPro.

Проект содержит классы:

1. Абстрактный класс ApiAbc, в нем определены следующие методы:
   - hh_get_city, определяет номер индекса города для поиска
   - hh_vacancies, получает и записывает вакансии
   
2. Абстрактный класс ABCJSONSaver, в нем определены следующие методы:
   - add_vacancy, добавляет вакансию в список
   - delete_vacancy, удаляет вакансию из списка
   - filter_vacancies, фильтрует вакансии

3. ApiHH, класс-наследник от класса ApiAbc.
Атрибутом класса является ссылка "https://api.hh.ru"

4. Vacancy, в нем определены следующие свойства:
   - job_title: str - название вакансии
   - link_to_vacancy: str - ссылка на вакансию
   - salary: str - зарплата
   - requirements: str. - описание вакансии
В данном класе определены методы:
   - __str__ - строковое представление,
   - __lt__ - сравнение по зарплате
   - __eq__ - сравнение по ссылке
   - __valid_requirements - приватный метод валидации для атрибута requirements
   - to_dict - метод для представления данных о вакансии в словаре
   - cast_to_object_list - классметод, возвращает список объектов Vacancy

5. JSONSaver, класс-наследник от класса ABCJSONSaver.
Атрибутом класса является путь к файлу с вакансиями


Проект содержит модуль utils с функциями:

1. create_vacansy_list_file.
Функция принимае путь до json файла с данными полученные от api HH, считывает данные из файла,
формирует лист с обьектами класса Vacancy, сортируетего и добавляет словарь
по каждому такому объекту в файл vacancy.json.
Возвращает список словарей с вакансиями отфильтрованными по критериям

Вкорне проекта модуль main с функцией user_interaction
для взаимодействия с пользователем


### В проект добавлены тесты для каждой функции и класса в модуле tests.
